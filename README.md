# 民国人生游戏设计文档仓库

这个仓库专门存放《民国人生》项目的**设计资产**，不以 demo 代码为中心。

## 当前权威入口

先读：

- `正式游戏设计圣经.md`：正式产品定义、系统、内容、表现与完成标准
- `十一条路径完整内容地图.md`：十一条路线从入口到死亡的现行制作索引
- `完整人生与1949后半生设计.md`：1949 后六种去向、晚年、死亡与完整终局规范
- `具体生活与人物连续性设计.md`：职业、父母、婚姻、子女、朋友、疾病和心理的逐年生活规范
- `公共生活与政治参与设计.md`：真实时代背景、合成公共网络、具体事务、家庭知情和压力后果
- `一生内容密度与复玩标准.md`：单局抉择密度、路线行动、跨年回响与复玩差异
- `数值与数据规范.md`：数值域、状态实体、年度结算、存档与迁移契约
- `史实审校与虚构标记规范.md`：史实来源、地区边界与合成叙事规则
- `正式制作交接清单.md`：冻结项、扩展项和正式游戏生产工作包
- `当前权威设计.md`：供快速阅读的设计总入口
- `文字版可试玩验收规格.md`：设计进入代码后必须满足的可测试条件

旧的系统看板、补完蓝图、剩余主链路总表和持续推进记录保留为推演历史。它们不再单独承担“当前运行时已经做到什么”的证明责任；运行时状态以 demo 仓库的 `PROTOTYPE_STATUS.md` 和回归结果为准。

## 说明

当前 v1.4.1 已把公共参与调整为“双层设计”：史实层保留真实事件和组织名称，个人玩法层使用具名的合成地方社团、行业互助组织与谨慎联络网络，不提供加入真实党派、潜入真实机构或选择指认对象的交互。文字版 v0.7.0 仍是调整前的研究原型，尚未对齐本版；目标文字版为 v0.8.0。后续正式公开产品仍需完成外部史实审校、内容与法律审核、玩家调优。本仓库允许保留 `unknown`，不会为了“看起来完整”而编造史实、制度细节或人物去向。
