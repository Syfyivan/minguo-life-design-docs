- `数值与数据规范.md`：数值域、状态实体、年度结算、存档与迁移契约
- `史实审校与虚构标记规范.md`：史实来源、地区边界与合成叙事规则
- `正式制作交接清单.md`：冻结项、扩展项和正式游戏生产工作包

- 本仓库：设计专用仓库，优先沉淀世界观、路径、状态机、规则层、整局推进看板与设计文档

当前文字版 `v0.7.14` 已公开接入 15 家庭／47 路径／8 去向：在旧三家庭切片之外，F05、F08–F18 中除 F02、F03、F07 外的十二个新增家庭，已按来源绑定和固定种子完整人生接入。47 条运行时路径映射到 32/48 个规范领域键；F15 新增 D12 仓储与民生供应交接、D33 民用机械维修与制图、D31 诊疗登记与基层文书，不为提高覆盖数字虚构领域。F15 的 7 项专项测试、三条完整人生、晚出生公共生活、父母唯一死亡与全量选项／行动可达性均已通过；功能提交 `41e547c`、Pages 任务 `31655010816` 及公网桌面／移动开局均已分别核验。十二个扩建家庭仍待最终史实与敏感性审校，其余 3 个未完成运行时回归的家庭继续隐藏；承载全部内容的完整文字验证版目标仍为 `v1.0.0`。

当前 design-v2.0.0 已纠正旧版把“三家庭十一路径”当成最终完成规模的问题：它们现在是首个垂直切片，F05、F08–F18 中除 F02、F03、F07 外的十二个家庭是此后按新规范接入的扩建家庭。正式首发范围扩展为九个区域生活圈、十八类出生家庭、四十八人生领域、八种 1949 后去向，并以不少于 5,000 条人工审校场景作为内容门槛。设计范围、schema 6 底座、八去向首轮可达和十二个新增家庭已经建立不等于内容全部写满，文字版 v0.7.14 也不能作为完整版已实现证明。后续仍需逐包完成内容、外部史实审校、敏感性阅读、运行时接入、完整人生回归与公开部署核验。本仓库允许保留 `unknown`，不会为了“看起来完整”而编造史实、制度细节或人物去向。
