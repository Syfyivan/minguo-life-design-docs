## 和 demo 仓库的关系

- demo / 可试玩原型仓库：`https://github.com/Syfyivan/minguo-life`
- 本仓库：设计专用仓库，优先沉淀世界观、路径、状态机、规则层、整局推进看板与设计文档

当前文字版 `v0.7.23` 已接入 18 家庭／71 路径／8 去向并覆盖 48/48 个规范领域键。在十五个领域首轮加厚之后，本轮为十八家庭各新增 12 条父母、朋友、婚姻、疾病、工作与顾客具体场景，共 216 条；所有正文都有具名人物、地点、实物、冲突、当年结果和后续影响，婚姻按男女处境分别解析。当前自动回归覆盖 71/71 条固定种子人生、6,248/6,248 个推进年份、1,165/1,165 个关键选项和 335/335 个行动。场景为 1,896/5,000，仍少至少 3,104 条；全部家庭和领域仍待继续加厚、逐场景史实与敏感性终审、144 条代表人生浏览器试玩和最终平衡，承载全部内容的目标仍为 `v1.0.0`。

## 说明

当前 design-v2.0.0 已纠正旧版把“三家庭十一路径”当成最终完成规模的问题：它们现在是首个垂直切片，十五个家庭是此后按新规范接入的扩建家庭。正式首发范围扩展为九个区域生活圈、十八类出生家庭、四十八人生领域、八种 1949 后去向，并以不少于 5,000 条人工审校场景作为内容门槛。设计范围、schema 6 底座、八去向首轮可达、十五个新增家庭、五批十五个完整领域包和第一批十八家庭生活密度包已经建立，不等于内容全部写满，文字版 v0.7.23 也不能作为完整版已实现证明。当前为 48/48 领域映射、1,896 条场景登记；后续仍需至少 3,104 条场景，并完成外部史实审校、敏感性阅读、144 条代表人生、企业全系统、完整人生回归与公开部署核验。本仓库允许保留 `unknown`，不会为了“看起来完整”而编造史实、制度细节或人物去向。
